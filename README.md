# fourcut studio

정적 웹사이트로 배포할 수 있는 네컷 사진 제작 앱입니다. 별도의 서버 API나 데이터베이스가 없으며, 사진 선택·촬영·프레임 편집·JPG 생성은 사용자의 브라우저 안에서 처리됩니다. 사진 순서 재배치, 사진별 확대와 위치 조정, 4·6·8칸 프레임 레이아웃, 카메라 촬영 타이머, 컬러·흑백 필터, 프레임 배경 사진, 사용자 문구 입력을 지원합니다. 미리보기 캔버스를 JPG로 저장하므로 저장 이미지와 같은 레이아웃으로 보입니다. 문구 입력란은 기본으로 비어 있습니다.

## 실행 및 배포

`index.html`, `style.css`, `app.js`를 같은 경로에 둔 상태로 정적 웹 호스팅에 게시하면 됩니다. 별도 빌드나 데이터베이스 설정은 필요하지 않습니다. 카메라 기능을 사용하려면 사이트를 HTTPS로 제공해야 합니다. 로컬 개발에서는 localhost에서 카메라 권한을 허용해주세요.

갤러리 사진과 카메라 촬영본은 서버로 업로드되지 않습니다. 완성된 네컷 사진은 브라우저에서 JPG 파일로 만들어 기기에 저장합니다.
